# Portfolio & Academic Research - Anshveer Bindra
Supplementary portfolio for undergraduate college applications.

## Contents
- **index.html**: Main interactive research portfolio with KaTeX mathematical typesetting, executive summaries, and embedded viewers.
- **papers/**: 7 complete research papers spanning astrophysics, theoretical physics, and pure mathematics.
- **music/**: Audio recording and sheet music score for String Quartet in E minor, "Future".
- **.nojekyll**: Ensures GitHub Pages serves all static files directly without Jekyll filtering.

## Deploying to GitHub Pages
1. Push this repository to GitHub (e.g. `anshveerbindra/research` or `anshveerbindra.github.io`).
2. Go to repository **Settings** &rarr; **Pages**.
3. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** (or `master`), folder: **/ (root)**
4. Click **Save**. Your site will be live within ~60 seconds!
